## 选题 1：DeepSeek 开源 dsh-superagent——群聊里不请自来的写码 Agent

**一句话爆点标题：** DeepSeek 把「主动干活的 coding Agent」开源了，默认还在「围观模式」

**30–60 秒口播脚本：**

> 11 月前后，DeepSeek Harness 团队在 GitHub 上开源了 **dsh-superagent**，MIT 协议，官方写得很直白：这是**研究原型，不是正式产品**。  
> 它盯一个 GitHub 仓库，可选接飞书；被授权的人 @ 它之后，Router 会拆任务，每个任务在**独立 Worker 会话**里跑，结果往往是一条 PR 回到原对话。  
> 有意思的点在于「主动」——团队文档里默认 **observe 围观**，要团队自己打开才会不请自来。  
> 安全也讲得很硬：跑在你本机 OS 用户权限下，DeepSeek 建议单独账号、单独机器。  
> 和 Claude Code、Copilot Agent 比，它更像一份可 fork 的**权限隔离架构样例**。你会让这样的 Agent 进公司群吗？评论区站队。

**分镜建议：**

1. 钩子：手机群聊 UI（模拟）→ 「@机器人 修个 bug」→ PR 通知弹出  
2. 架构图：Router → 多个 Worker 小窗口并行  
3. GitHub 仓库 README 关键词高亮：「research prototype」「MIT」  
4. 对比表快闪：触发方式 / 是否 proactive / 跑在哪里  
5. 结尾：二元选择贴纸「敢用 / 先围观」

**画面/素材方向：** GitHub `deepseek-ai/dsh-superagent-prototype` 页面录屏；Harness 面板示意图；飞书/钉钉风格群聊（需注明模拟）；PR merge 动画。

**封面文案：** DeepSeek 开源「主动写码 Agent」｜默认只围观

## 完整方案（传播潜力 TOP 1）：DeepSeek dsh-superagent

### 内容形态

- **时长：** 90–120 秒（抖音可剪 60 秒版）  
- **人设：** 科技资讯主理人，偏开发者友好、不吹不黑  
- **基调：** 「开源可玩，但默认围观 + 权限隔离必做」

### 开头钩子（0–5 秒）

- 视觉：群聊里同事 @ 你修 bug，你还没回，**另一个账号已经推了 PR**。  
- 口播：「如果写代码的 AI 不用你喊，自己会进群里接单，你怕不怕？」

### 正文节奏（5–75 秒）

| 时间段 | 信息点 | 字幕重点 |
|--------|--------|----------|
| 5–20s | 事件：DeepSeek Harness 开源 **dsh-superagent**，MIT | 「研究原型 · 非正式产品」 |
| 20–40s | 机制：Router / Worker 隔离；可选飞书 + GitHub | 「一任务一会话」 |
| 40–55s | 主动模式默认 **observe**；需团队手动开启 | 「默认围观，不是默认打工」 |
| 55–70s | 安全：OS 级权限；建议独立账号与机器 | 「别用日常账号硬跑」 |
| 70–75s | 对比：Copilot Agent / Claude Code 等（口述，避免贬损） | 「架构参考 > 成品替代」 |
